# Mixbar releases

Notarized builds of Mixbar (a macOS menu-bar app for per-app audio control) and the Sparkle appcast the app checks for updates.

1.x builds were zips generated by `tools/release.sh` in the main repo. From 2.0 on, releases are installer packages built by `cargo xtask release-pkg`, and the appcast item comes from `cargo xtask appcast-item` (see `docs/2.0/releasing.md` there). Both sign with the Sparkle EdDSA key in the maintainer's keychain. Artifacts are attached to GitHub releases.
